# Digital Treehouse Studio

Actúa como un diseñador UX/UI experto y desarrollador front-end. Quiero crear la estructura, el diseño y la navegación inicial de una aplicación web infantil llamada 'El Árbol Digital'.

Estilo Visual:

Estética orgánica, minimalista y editorial (tipo libro ilustrado moderno, mucho espacio en blanco).

Paleta de colores: Tonos verdes salvia, crema, tierra suave y un toque de amarillo mostaza para detalles.

Tipografía: Una fuente sans-serif geométrica y muy legible para niños (tipo Poppins o Quicksand).

Estructura y Componentes (constrúyelo todo en este primer paso):

Menú de navegación superior limpio que permita cambiar de vista de forma fluida.

Página de Inicio (Home):

Una sección 'Hero' central con una ilustración estilizada de un árbol que da la bienvenida.

Debajo del árbol, tres tarjetas de navegación grandes, con bordes redondeados y sombras muy sutiles, que den acceso a las tres secciones principales: 'Biblioteca de Cuentos' (libro abierto), 'Zona de Juegos' (pieza de rompecabezas) y 'Rincón de Manualidades' (pincel).

Vista interna de 'Biblioteca de Cuentos':

Un par de tarjetas de historias de ejemplo con un diseño limpio para que se vea funcional.

Vista interna de 'Zona de Juegos':

Un espacio básico preparado para minijuegos.
